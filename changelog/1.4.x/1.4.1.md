# 1.4.1 — 2026-10-24

## Changed

- **Tool error and recovery text in `content[]` is Markdown-escaped** (mcp-ts-core 0.13.16, [cyanheads/mcp-ts-core#760](https://github.com/cyanheads/mcp-ts-core/issues/760)). `structuredContent` keeps the raw string: an invalid color `not_a*color_` reads `not_a\*color\_` in `content[]`.
- **Numeric and boolean strings in tool arguments are repaired before validation** (0.13.14, [cyanheads/mcp-ts-core#707](https://github.com/cyanheads/mcp-ts-core/issues/707)): `"4"` for `x`/`y`/`w`/`h` on `pixoo_compose_scene`, `push: "false"` and `speed: "200"` on `pixoo_push_image`, `frames: "2"` on `pixoo_render_html`.
- **An out-of-range framework environment value stops startup with the variable named** (0.13.16, [cyanheads/mcp-ts-core#747](https://github.com/cyanheads/mcp-ts-core/issues/747)). `MCP_HTTP_PORT=1.5` started 1.4.0; 1.4.1 stops with `MCP_HTTP_PORT (mcpHttpPort): Invalid input: expected int, received number`.
- **Device names, device error messages, page errors, and saved file paths echoed into `content[]` are Markdown-escaped**: names in `pixoo_discover_devices` (IPs render as inline code), failure notices in `pixoo_control_device` and `pixoo_display_text`, `pageErrors` in `pixoo_render_html`, and `Saved:` paths in `pixoo_compose_scene`, `pixoo_display_text`, `pixoo_push_image`, and `pixoo_render_html`.
- **`errors[].when` wording is aligned across tools**: `no_device_configured` reads "PIXOO_IP is not set and push was requested." and `device_unreachable` reads "Device is not reachable over the network."
- **The `finish` rejection for an over-long `palette` now reports the union's branches** (`colors: Invalid input: expected number, received undefined; Unrecognized key: "palette" or palette: Too big`), from zod 4.6.7.
- **`server.json` npm entries no longer pass `run start:*`** and use `runtimeHint: "npx"`; the `streamable-http` entry sets `MCP_TRANSPORT_TYPE` to `http`.
- **The Docker image's deps stage removes sharp's musl-only packages** (`@img/sharp-linuxmusl-*`, `@img/sharp-libvips-linuxmusl-*`), which the glibc runtime never loads, via `scripts/prune-musl-packages.ts`. The image builds on Bun 1.4.4 (from 1.4.2).
- **Env-file ignore rules widen to `.env*`** in `.gitignore` and `.dockerignore`; CodeQL runs one job per language; framework skills, `scripts/devcheck.ts`, `scripts/lint-packaging.ts`, and `scripts/check-framework-antipatterns.ts` are resynced to 0.13.16.
