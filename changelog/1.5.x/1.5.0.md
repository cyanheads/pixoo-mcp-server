# 1.5.0 — 2026-10-28

## Added

- **`pixoo-guide` agent skill**: `skills/pixoo-guide/SKILL.md`, served over MCP as the `skill://pixoo-guide/SKILL.md` resource with the `skill://{+path}` template, and shipped in the npm package, `.mcpb` bundle, and Docker image. The server `instructions` point to it.
- **Root `plugin.json` and `mcp.json`**: the Agent Plugins 1.0.0 pair, beside the existing `.claude-plugin/` and `.codex-plugin/` manifests.

## Changed

- **Framework `@cyanheads/mcp-ts-core` ^0.13.16 → ^0.13.18 (MCP SDK 2.4.0).** 0.13.17 fixes a per-request memory leak in the HTTP transport: under Bun, the runtime the Docker image runs, 1.4.1 retained memory on every Streamable HTTP request, so sustained traffic grew the heap until the process ran out of memory. 0.13.18 adds the published-skills support this release uses.
- **`pixoo_compose_scene` `amplitude` description**: `float` swings ±`amplitude` px vertically, `drift` ±4 × `amplitude` px horizontally, and `scroll-left` / `scroll-right` move 2 × `amplitude` px per frame from where the element is placed, with no wrap.
- **`pixoo_design_brief` `displaySize` and `reachable` descriptions**: coordinates are panel pixels and do not scale with `displaySize`; `reachable: false` covers both an unconfigured and an unanswering device and does not make render tools default to `push: false`.
- **Render determinism text** (`pixoo_render_html` description, the `html` design-brief topic, README, `docs/design.md`): two calls capture the same frames unless the page reads `Math.random` (unseeded) or the starting `Date`.
- **`.mcpb` packaging**: `scripts/clean-mcpb.ts` and `lint:packaging` remove dependency agent docs only at an installed package root, so the MCP SDK's runtime `dist/ext/skills/` modules stay in the bundle (cyanheads/mcp-ts-core#794); `tests/scripts/agent-doc-entry.test.ts` asserts the two matchers agree. `.mcpbignore` lists each root dev path root-anchored.
- **Framework sync to 0.13.18**: `framework-skills/` (new `add-skill`), `scripts/`, issue forms, `SECURITY.md`, `bunfig.toml` `minimumReleaseAge` 3 days → 1 day, and a shorter README Getting started.
- **`tests/renderer/finish.test.ts`**: the 64 px multi-column palette case runs 200 frames instead of 800 to stay inside vitest's default timeout on a loaded machine.
